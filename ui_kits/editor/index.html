Inkwell editor UI kit

This folder used to load React via Babel in the browser. The project now uses Vite + React from the repository root.

  1. cd to the project directory (parent of ui_kits).
  2. Run yarn install then yarn dev.
  3. Open the local URL Vite prints (typically http://localhost:5173/).

Source: src/App.jsx composes the components in this directory.
